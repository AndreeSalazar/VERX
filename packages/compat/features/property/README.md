# Propiedades CSS animables (@property)

| Navegador | |
|---|---|
| Chrome / Edge / Brave | desde 85 |
| Safari | desde 16.4 |
| Firefox | desde 128 |

**Sin ella:** la propiedad no se anima y se hereda como cualquier variable.

Si falta, **se pierde un detalle sin romper nada**: el guardián no bloquea, lo informa, y VERX Grafo lo enseña en ámbar.

**Sin respaldo.**

Se detecta en el código por: `@property`.
