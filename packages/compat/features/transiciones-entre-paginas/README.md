# Transiciones entre páginas (@view-transition)

| Navegador | |
|---|---|
| Chrome / Edge / Brave | desde 126 |
| Safari | desde 18.2 |
| Firefox | **no la tiene** |

**Sin ella:** se navega normal, sin la animación de hundirse y emerger.

Si falta, **se pierde un detalle sin romper nada**: el guardián no bloquea, lo informa, y VERX Grafo lo enseña en ámbar.

**Sin respaldo.**

Se detecta en el código por: `@view-transition`.
