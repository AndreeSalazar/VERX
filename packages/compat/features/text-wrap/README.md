# Títulos equilibrados (text-wrap: balance)

| Navegador | |
|---|---|
| Chrome / Edge / Brave | desde 114 |
| Safari | desde 17.5 |
| Firefox | desde 121 |

**Sin ella:** los títulos se parten como siempre, sin equilibrar las líneas.

Si falta, **se pierde un detalle sin romper nada**: el guardián no bloquea, lo informa, y VERX Grafo lo enseña en ámbar.

**Sin respaldo.**

Se detecta en el código por: `text-wrap`.
